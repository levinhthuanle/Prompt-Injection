# Course Catalog — Example University

## Department of Computer Science

### CS101 — Introduction to Programming (3 credits)
Instructor: Prof. Johnson
Semester: Fall/Spring

An introductory course covering the fundamentals of programming using Python. Students will learn variables, data types, control flow, loops, functions, and basic data structures such as lists and dictionaries. No prior programming experience required.

Prerequisites: None
Assessment: 3 quizzes, 5 assignments, 1 final project

---

### CS201 — Data Structures and Algorithms (4 credits)
Instructor: Prof. Smith
Semester: Fall/Spring

Advanced data structures including linked lists, stacks, queues, trees, graphs, and hash tables. Topics include algorithm analysis (Big-O notation), sorting algorithms, searching algorithms, and dynamic programming.

Prerequisites: CS101
Assessment: 4 assignments, 2 midterms, 1 final exam

---

### CS301 — Operating Systems (3 credits)
Instructor: Prof. Williams
Semester: Fall

Process management, memory management, file systems, concurrency, and deadlocks. Practical labs using Linux.

Prerequisites: CS201
Assessment: Labs, 2 exams, 1 project

---

### CS401 — Computer Networks (3 credits)
Instructor: Prof. Brown
Semester: Spring

Network architecture, protocols (TCP/IP, UDP, HTTP), routing algorithms, and an introduction to network security.

Prerequisites: CS301

---

## Department of Cybersecurity

### SEC101 — Introduction to Cybersecurity (3 credits)
Instructor: Prof. Davis

Security fundamentals: threat modeling, cryptography basics (symmetric/asymmetric, hashing), authentication, and security policies. Students complete hands-on labs in a sandboxed environment.

Prerequisites: None

---

### SEC201 — Network Security (3 credits)
Instructor: Prof. Wilson

Firewalls, intrusion detection systems (IDS/IPS), VPNs, penetration testing basics, and secure network design principles.

Prerequisites: SEC101, CS401

---

## Department of Data Science

### DS101 — Introduction to Data Science (3 credits)
Instructor: Prof. Anderson

Data analysis with Python (pandas, NumPy, matplotlib), statistical methods, and data visualization.

Prerequisites: CS101, MATH101

---

### DS201 — Machine Learning (4 credits)
Instructor: Prof. Taylor

Supervised learning (regression, classification), unsupervised learning (clustering), neural network basics, and model evaluation.

Prerequisites: DS101, MATH201

---

## Department of Mathematics

### MATH101 — Calculus I (4 credits)
Instructor: Prof. Martinez

Limits, derivatives, integrals of single-variable functions, and applications.

### MATH201 — Linear Algebra (3 credits)
Instructor: Prof. Garcia

Vectors, matrices, linear transformations, eigenvalues and eigenvectors, and applications in computer science.
